## Sistema Operacional (SO)

### O que é um Sistema Operacional?

O **Sistema Operacional (SO)** é um software (ou conjunto de softwares) responsável por gerenciar todos os recursos de um computador. Ele atua como intermediário entre o usuário, os programas e o hardware, permitindo que todos os componentes funcionem de forma organizada e eficiente.

Sem um sistema operacional, não seria possível utilizar o computador de maneira prática, pois ele é responsável por controlar e coordenar o funcionamento dos dispositivos e aplicativos.

---

# Principais Funções do Sistema Operacional

O SO realiza diversas tarefas essenciais para o funcionamento do computador, entre elas:

### Gerenciamento de Processos
- Controla os programas que estão sendo executados.
- Distribui o tempo de processamento da CPU entre os processos.
- Permite a execução simultânea de vários programas (multitarefa).

### Gerenciamento de Memória
- Controla o uso da memória RAM.
- Aloca e libera memória para os programas conforme necessário.
- Evita conflitos entre aplicações.

### Gerenciamento de Recursos
- Administra recursos como:
  - CPU
  - Memória
  - Disco
  - Rede
  - Impressoras
  - Outros dispositivos conectados

### Gerenciamento de Hardware
- Faz a comunicação entre o software e os componentes físicos do computador.
- Utiliza drivers para controlar dispositivos como:
  - Teclado
  - Mouse
  - Monitor
  - Disco rígido (HD/SSD)
  - Placa de vídeo
  - Impressoras
  - Entre outros.

---

## Gerenciador de Tarefas (Windows)

O **Gerenciador de Tarefas** permite monitorar o desempenho do computador e acompanhar os programas em execução.

### Como abrir

Pressione:

```text
Ctrl + Alt + Delete
```

Em seguida, selecione **Gerenciador de Tarefas**.

Ou utilize o atalho direto:

```text
Ctrl + Shift + Esc
```

---

## Informações disponíveis no Gerenciador de Tarefas

No Gerenciador de Tarefas é possível visualizar informações importantes, como:

- Utilização da CPU (%)
- Consumo de memória RAM
- Uso do disco (HD/SSD)
- Utilização da rede
- Uso da GPU (placa de vídeo)
- Programas e processos em execução
- Programas que iniciam junto com o Windows
- Usuários conectados ao sistema
- Serviços do Windows em execução

---

## Resumo

O Sistema Operacional é responsável por:

- Gerenciar processos;
- Gerenciar memória;
- Gerenciar recursos do computador;
- Gerenciar o hardware;
- Permitir a comunicação entre usuário, programas e dispositivos.

O **Gerenciador de Tarefas** é uma ferramenta importante para acompanhar o desempenho do computador e identificar possíveis problemas de uso de recursos.
