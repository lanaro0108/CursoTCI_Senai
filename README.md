# **Curso Tecnologia da Comunicação e Informação**

## Aula 1 - Sistema Operacional (SO)

### O que é um Sistema Operacional?

O **Sistema Operacional (SO)** é um software (ou conjunto de softwares) responsável por gerenciar todos os recursos de um computador. Ele atua como intermediário entre o usuário, os programas e o hardware, permitindo que todos os componentes funcionem de forma organizada e eficiente.

Sem um sistema operacional, não seria possível utilizar o computador de maneira prática, pois ele é responsável por controlar e coordenar o funcionamento dos dispositivos e aplicativos.

---

## Principais Funções do Sistema Operacional

O SO realiza diversas tarefas essenciais para o funcionamento do computador, entre elas:

### Gerenciamento de Processos
- Controla os programas que estão sendo executados.
- Distribui o tempo de processamento da CPU entre os processos.
- Permite a execução simultânea de vários programas (multitarefa).

### Gerenciamento de Memória
- Controla o uso da memória RAM.
- Aloca e libera memória para os programas conforme necessário.
- Evita conflitos entre aplicações.

### Gerenciamento de Recursos
- Administra recursos como:
  - CPU
  - Memória
  - Disco
  - Rede
  - Impressoras
  - Outros dispositivos conectados

### Gerenciamento de Hardware
- Faz a comunicação entre o software e os componentes físicos do computador.
- Utiliza drivers para controlar dispositivos como:
  - Teclado
  - Mouse
  - Monitor
  - Disco rígido (HD/SSD)
  - Placa de vídeo
  - Impressoras
  - Entre outros.

---

## Gerenciador de Tarefas (Windows)

O **Gerenciador de Tarefas** permite monitorar o desempenho do computador e acompanhar os programas em execução.

### Como abrir

Pressione:

```text
Ctrl + Alt + Delete
```

Em seguida, selecione **Gerenciador de Tarefas**.

Ou utilize o atalho direto:

```text
Ctrl + Shift + Esc
```

---

## Informações disponíveis no Gerenciador de Tarefas

No Gerenciador de Tarefas é possível visualizar informações importantes, como:

- Utilização da CPU (%)
- Consumo de memória RAM
- Uso do disco (HD/SSD)
- Utilização da rede
- Uso da GPU (placa de vídeo)
- Programas e processos em execução
- Programas que iniciam junto com o Windows
- Usuários conectados ao sistema
- Serviços do Windows em execução

---

## Resumo

O Sistema Operacional é responsável por:

- Gerenciar processos;
- Gerenciar memória;
- Gerenciar recursos do computador;
- Gerenciar o hardware;
- Permitir a comunicação entre usuário, programas e dispositivos.

O **Gerenciador de Tarefas** é uma ferramenta importante para acompanhar o desempenho do computador e identificar possíveis problemas de uso de recursos.

## Aula 2 - Softwares e Licenciamento # Licenciamento de Software

### O que é o licenciamento de software?

Todo software é distribuído com uma **licença de uso**, que define os direitos e deveres do usuário. Durante a instalação, é comum que seja exibido um contrato de licença (EULA), que precisa ser aceito para que a instalação seja concluída.

A licença determina, por exemplo, se o software pode ser copiado, modificado, redistribuído ou utilizado para fins comerciais.

---

## Principais tipos de licença

### Software Livre (Free Software)

O **software livre** garante ao usuário liberdade para utilizar, estudar, modificar e compartilhar o programa. Segundo a **Free Software Foundation (FSF)**, um software é considerado livre quando oferece as quatro liberdades:

1. Executar o programa para qualquer finalidade.
2. Estudar como ele funciona e modificá-lo (acesso ao código-fonte).
3. Redistribuir cópias.
4. Melhorar o programa e compartilhar essas melhorias com a comunidade.

#### Exemplos

- Mozilla Firefox
- Mozilla Thunderbird
- LibreOffice
- VLC Media Player
- GIMP

> **Importante:** Software livre **não significa necessariamente gratuito**. Ele pode ser pago, desde que mantenha essas liberdades.

---

### Software Proprietário

É um software cujo **código-fonte não é disponibilizado** ao usuário. A cópia, modificação e redistribuição dependem da autorização do desenvolvedor.

Pode ser gratuito ou pago, conforme a decisão da empresa responsável.

#### Exemplos

- Microsoft Windows
- Microsoft Office
- Adobe Photoshop
- AutoCAD
- CorelDRAW

---

### Software Comercial

São programas desenvolvidos para venda ou assinatura. Na maioria dos casos também são proprietários, embora existam softwares livres comercializados.

#### Exemplos

- Microsoft 365
- Adobe Creative Cloud
- Vegas Pro
- SolidWorks

---

### Freeware (Software Gratuito)

O **freeware** pode ser utilizado gratuitamente, porém normalmente continua sendo proprietário. Em muitos casos, o usuário não pode modificar nem redistribuir o programa.

Alguns possuem restrições de uso, sendo gratuitos apenas para uso pessoal ou educacional.

#### Exemplos

- Adobe Acrobat Reader
- Zoom
- Google Chrome
- Skype

---

## Pirataria de Software

Antes de instalar qualquer programa, é importante verificar sua licença.

Utilizar softwares pagos sem licença válida, ou distribuir cópias não autorizadas, caracteriza **pirataria**, que é crime no Brasil.

As principais leis que protegem os programas de computador são:

- **Lei nº 9.609/1998** (Lei do Software)
- **Lei nº 9.610/1998** (Lei dos Direitos Autorais)

As penalidades podem incluir:

- Multas;
- Indenização por danos ao titular dos direitos;
- Detenção ou reclusão, dependendo da infração e da finalidade (como reprodução para comércio).
